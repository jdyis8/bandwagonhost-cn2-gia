## BiggerBox Pro 是什么：一套配置先看明白

BiggerBox Pro 是搬瓦工（BandwagonHost，母公司 IT7 Networks）Box Pro 系列里的入门款，官方套餐名 **BIGGERBOX-PRO**，部署在洛杉矶新开的 DC1 机房（USCA_1）。核心参数如下：

| CPU | 1 核 AMD EPYC 9004 系列 |
| 内存 | 1 GB |
| 硬盘 | 20 GB SSD（RAID-10） |
| 月流量 | 1000 GB |
| 带宽 | 2.5 Gbps |
| 机房 | 洛杉矶 DC1 |
| 线路 | 电信 CN2 GIA，联通、移动 CMIN2 |
| 价格 | $39.00/年，仅年付 |

有几个点值得单独说一下。

**CPU 是这次升级的大头。** 之前的 DC99 系列 Box 用的是较老平台，Box Pro 系列换成了 AMD EPYC 9004 系列。第三方测评站"主机测评"实际开了一台测试，显示磁盘 I/O 大约在 993 MB/s，FIO 读写数据也过得去，对一台年付39美元的小鸡来说，这个性能底子不算寒酸。

**2.5 Gbps 带宽是 DC1 的标准配置。** 老的 DC99 Box 系列只有 1 Gbps，DC1 直接翻了2.5倍。

**流量 1 TB/月。** 拿来做个人代理、跑轻量网站、挂机器人，基本够用；但如果你想全家共享或跑大流量服务，往后看 MegaBox Pro 的部分。

## 线路质量：三网走向实测数据怎么说

买搬瓦工的人，本质上买的是线路。BiggerBox Pro 的官方标注是"Direct Premium China connectivity"，具体走向结合测评站的 traceroute 数据是这样的：

- **电信**：去程和回程都走 CN2 GIA（59.43 开头的 CN2 骨干网），延迟大约在 130–160ms 之间，晚高峰测试也没有明显劣化；
- **联通**：去程走 AS4837 直达洛杉矶，回程则强制走移动的 CMIN2 链路回国，全程洛杉矶到国内没有绕路；
- **移动**：去回程都走自家高端 CMIN2 线路，延迟 126–155ms 左右。

一句话概括：电信吃 CN2 GIA，联通和移动吃 CMIN2，三条线路都是各自阵营里的高端货。测评站的原话是"36美元一年给三网都上了高端优化线路的 AMD 小鸡还是少见的"，这个评价放在这个价位段基本成立。

和它最接近的对比对象是搬瓦工常规在售的 CN2 GIA-E 套餐：同样是 1GB 内存、20GB 硬盘、1TB 流量、2.5 Gbps，年付 **$49.99**，比 BiggerBox Pro 贵了约 11 美元。差别在于 CN2 GIA-E 支持机房迁移（DC6、DC9、日本、欧洲等节点可切换），而 BiggerBox Pro 锁死在 DC1。如果你不需要换机房，Pro 便宜这一截就是纯赚。

## BiggerBox Pro vs MegaBox Pro：多花10美元值不值

两款 Pro 套餐同机房同线路，差价10美元/年，配置差了一个档次：CPU 翻倍（1核到2核）、内存翻倍（1GB 到 2GB）、硬盘和流量也各翻一倍。

另外，搬瓦工官方限制每款套餐的 CPU 占比上限，按官网注册页公示的数据：MiniBox 为单核的 20%，BiggerBox 为 25%，PowerBox 和 MegaBox 为 30%。换句话说，1GB 内存的套餐不只是内存小，持续能吃满的 CPU 份额也更少。

我的判断标准很简单：如果这台机器只跑代理或一两个轻量服务，BiggerBox Pro 的 1GB 够用；只要你有建站、跑数据库、多个服务并存的打算，2GB 内存的 MegaBox Pro 更稳妥——Linux 上 1GB 内存跑多了服务之后，swap 抖动是常态。补货时两款通常同时上架，先到先得。
